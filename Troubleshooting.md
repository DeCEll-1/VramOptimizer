# AMD GPUs

If you are experiencing graphical glitches or crashes on an AMD GPU, try one of the following two solutions:

## Option 1: Disable Mipmaps in `settings.json`

Set `"VOpt_no_mipmap"` to `true` in your `settings.json` file, which is located on  `VRAMOptimizer/data/config/settings.json`

## Option 2: Install Fast Rendering v0.8.9

If disabling mipmaps does not resolve the issue(s), install **Fast Rendering version 0.8.9 or above**:

[Fast Rendering Forum Page](https://fractalsoftworks.com/forum/index.php?topic=33870.0)
